# GASフォーム自動化キット

Google フォームに申し込みがあるたびに、手作業でやっている「転記・返信・連絡」を自動化する Google Apps Script（GAS）一式です。

フォームが送信されると、自動で次の3つが動きます。

1. **整形して記録** — 回答を「受付ログ」シートに整形して蓄積（見出し整形・行の自動追加）
2. **自動返信メール** — 申込者へ受付完了メールを送信（本文は項目差し込み対応のテンプレート）
3. **管理者へ通知** — Slack / LINE / メールに「新しい申し込み」の内容を即時通知

セミナー申込、予約受付、問い合わせ、資料請求など、「フォームのあと処理」が定型の業務に向いています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Config.gs` | 設定（シート名、返信文テンプレート、通知タイトルなど）。導入時に編集するのは原則ここだけ |
| `Code.gs` | メイン処理（送信トリガー → ログ記録 → 返信 → 通知、未処理分のまとめ処理） |
| `Mail.gs` | 自動返信メールのテンプレート差し込み |
| `Notify.gs` | Slack / LINE 通知 |
| `Setup.gs` | セットアップ関数とスプレッドシートのカスタムメニュー |
| `appsscript.json` | マニフェスト（タイムゾーン Asia/Tokyo、V8ランタイム） |

## 導入手順

### 1. フォームと回答スプレッドシートを用意する

1. Google フォームを作成します（質問項目は自由です）。
2. 自動返信を使いたい場合は、**メールアドレスを入力する質問項目**を入れてください（見出しに「メールアドレス」と付けるのが確実です）。フォームの設定で「メールアドレスを収集する」を有効にしても構いません。
3. フォームの「回答」タブから、スプレッドシートにリンクして回答用スプレッドシートを作成します。

### 2. スクリプトを貼り付ける

1. 回答スプレッドシートを開き、メニュー **拡張機能 > Apps Script** を開きます。
2. 既定の `Code.gs` を削除し、本キットの5つの `.gs` ファイルを同じ名前で作成して内容を貼り付けます。
3. 左下の「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」を有効にし、同梱の `appsscript.json` の内容に置き換えます（任意。タイムゾーンを日本時間に固定するためのものです）。

> clasp を使える方は、このフォルダをそのまま `clasp push` しても構いません。

### 3. 設定を編集する（Config.gs）

- `REPLY_SUBJECT` / `REPLY_BODY` — 自動返信メールの件名と本文。本文中の `{{お名前}}` のような書き方は、その見出しの回答に自動で置き換わります。`{{全項目}}` は全回答の一覧、`{{タイムスタンプ}}` は受付日時です。
- `ADMIN_EMAIL` — 管理者にもメールで通知したい場合に記入（不要なら空のまま）。
- `EMAIL_COLUMN_HEADER` — メールアドレスの列の見出しが「メール」「email」を含まない場合のみ指定。

### 4. 通知先を登録する（任意・スクリプト プロパティ）

Webhook URL やトークンはコードに書かず、スクリプト プロパティに登録します。

Apps Script エディタの **プロジェクトの設定 > スクリプト プロパティ** で、使うものだけ追加してください。

| プロパティ名 | 値 | 取得方法 |
|---|---|---|
| `SLACK_WEBHOOK_URL` | Slack Incoming Webhook の URL | Slack App 管理画面で対象チャンネルの Webhook を発行 |
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE チャネルアクセストークン（長期） | LINE Developers コンソールで公式アカウントの Messaging API チャネルから発行 |
| `LINE_TO_ID` | 送信先のユーザーID / グループID | 公式アカウントの管理画面や Webhook 受信ログで確認 |

※ LINE Notify は 2025年3月末でサービス終了したため、本キットは LINE 公式アカウントの Messaging API で送信します。

### 5. セットアップを実行する

1. Apps Script エディタで `Setup.gs` の `setupAutomation` を選んで実行します。
2. 初回は Google アカウントの承認ダイアログが出ます（自分のスクリプトへの権限許可です）。
3. 完了すると、スプレッドシートに **「フォーム自動化」メニュー** が追加され、「受付ログ」シートが作成されます。

### 6. 動作確認

1. メニュー **フォーム自動化 > テスト通知を送る** で、Slack / LINE / 管理者メールにテストが届くか確認します。
2. フォームから実際にテスト送信し、①受付ログに行が増える ②自動返信メールが届く ③通知が届く、の3点を確認します。

## 運用メモ

- **トリガーが止まった期間の穴埋め**: メニュー「フォーム自動化 > 未処理分をまとめて処理」で、未処理の回答を一括処理できます（処理済みの行は記録しているため二重送信しません）。
- **止めたいとき**: メニュー「フォーム自動化 > トリガーを削除（停止）」で即時停止できます。
- **文面の変更**: Config.gs のテンプレートを編集するだけで反映されます（トリガーの再登録は不要）。
- **送信上限**: 自動返信は Google アカウントのメール送信上限（無料アカウントで1日100通まで等）の範囲で動きます。大量受付のフォームでは Workspace アカウントでの運用を推奨します。

## カスタマイズ例（案件でよくある追加）

- 申込内容に応じた条件分岐（例: 希望コースごとに返信文・通知先を変える）
- Google カレンダーへの仮予定の自動登録
- 回答内容から PDF（受付票・請求書）を生成して自動添付
- 顧客管理シートへの転記、重複申込の検知
- 申込締切後の自動クローズ（フォームの受付停止と連動）
